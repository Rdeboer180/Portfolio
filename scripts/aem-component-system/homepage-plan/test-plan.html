The test behind each concept

A concept enters the file with a hypothesis, the data it needs, and the tests it has to wait for. Nothing is built from an assumption alone.

Hypothesis: the How It Works order

Shoppers scrolling for shipping, delivery, and testing answers will read a section that leads with them.

The last redesign led with Find, Deliver, Install. Find is now an expectation rather than a question, so delivery and installation become the first tab, then shipping, returns, and testing, which are the brand’s distinct advantages.

Before building on that assumption, the section ships without an order and the order comes from customers.

Data to request: engagement with How It Works against the promotion banners.

Hypothesis: the promotions carousel

Deal-centric shoppers will find a smaller carousel placed above the fold.

The carousel moves up the page and shrinks from 550 × 470 banners to 490 × 180, so it reads as a lane rather than a billboard. The two best-selling days of last year were deal days, so the lane earns its place near the top.

Competitor homepages were read for placement, not copied.

Data to request: carousel engagement by position.
